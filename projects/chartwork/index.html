Letting the notes draw the charts

2026-11-03

My Obsidian vault was full of charts. Some counted books by reading status or notes created each month by tag, and a few drew series typed in by hand. Almost every one was a raw chart config handed to the Charts plugin from a script. The helper behind the bar charts had grown to about 70 lines, mostly to read the theme’s colors so labels stayed visible in dark mode and to put the count on each bar.

Then Obsidian added Bases, which turns note properties into tables, and a handful of chart plugins appeared for it. Each covered part of what the vault needed, so it would have taken two or three of them side by side.

Chartwork handles Bases views, code blocks and scripts in one plugin. A Bases view gets a chart layout with no code at all. You pick a property and whether to count or add up, and the chart redraws as the options change. A chart code block holds numbers typed into the note, and a script hands over numbers it has worked out first, in one short call.

All three draw the same way, with the theme’s colors and the value on each bar. Dates can be grouped by week or month, leaving a gap where nothing happened, and the top few categories kept with the rest added up as “Others”. A chart that needed the helper became a call of about ten lines, and the older notes written for Charts draw as they are.
